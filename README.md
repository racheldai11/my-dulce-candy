# My Dulce Candy

**Descripción del proyecto**

My Dulce Candy es una página web de pastelería creada para presentar productos dulces, mostrar reseñas de clientes y facilitar el contacto para realizar pedidos.

**Tecnologías utilizadas**

- HTML5
- CSS3
- Flexbox y Grid
- Google Fonts
- Formspree para el formulario de contacto

**Contenido**

- Inicio
- Productos
- Reseñas
- Contacto
